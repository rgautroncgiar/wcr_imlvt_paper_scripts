# Companion Repository

This repository is the companion code and data repository for the article:

**“Exploring Arabica coffee genotype-by-environment interactions (G×E) along climate gradients: findings from the international multi-location variety trial.”**

It contains the data and analysis scripts used to support and reproduce the analyses presented in the article.

## Repository structure

- `source_data/` — all data files required to run the analyses.
- `Python/` — Python scripts used for data analysis and visualization.
- `R/` — R scripts used for statistical analyses and related workflows.
