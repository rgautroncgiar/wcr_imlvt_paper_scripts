# Scripts Overview

## `fa_biplot(3).py`
Creates FA biplots **yield** and **rust** IMLVT analysis data

## `heatmap_fas(2).py`
Creates heatmaps of **FA1/FA2 scores** for genotypes and environments for both **yield** and **rust** IMLVT analysis data

## `plsr_py(4).py`
Runs **Partial Least Squares Regression (PLSR)** to relate climate/geographic variables to FA1 and FA2, producing correlation plots, predictions, coefficients, VIP scores, explained variance, and permutation-test results.

## `pretty_pca_wcr_article(5).py`
Runs **PCA with optional varimax rotation** on climate variables and creates climate representativeness plots comparing WCR trial sites with baseline and future climate distributions.
